# 0003. uv.lock is the only Python dependency source

`svc/uv.lock` is the single exact pin for every Python dependency, and every environment installs from it with `uv sync --frozen`: CI's `backend-tests` job, the Docker image, and the Windows Sensor Agent, which also gets its Python interpreter from uv. `svc/pyproject.toml` lists only minimum versions and `requires-python`, there is no `requirements.txt` or pip install path, and nobody edits the lock by hand; dependencies change only through `uv add` or `uv lock --upgrade`, and the updated lock is reviewed like code. We chose this so that the code CI tests is byte-for-byte the code that runs on the trailer, replacing the earlier mix of pip instructions and exact pins in `pyproject.toml` that could drift apart. The interpreter and tool versions are held to the same standard: `scripts/check-runtime-versions.sh` fails the `docker-builds` job when the Dockerfile's Python, Node, or uv version differs from `svc/.python-version`, `.nvmrc`, or the uv version pinned in `.github/workflows/ci.yml`. The trade-off is that every contributor needs uv installed, and a Dependabot bump to one file stays red until the others are updated to match.
